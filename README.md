# EduRAG

一个面向教育场景的问答系统。核心思路是分两层：常见问题直接用 BM25 从 FAQ 库里匹配返回，不走大模型；匹配不上或者置信度不够的，再进 RAG 流程检索生成。这样响应快，成本也低。

## 做了什么

文档入库支持 PDF、Word、PPT 和图片（走 OCR）。解析完做父子分块——父块 1200 字保上下文完整，子块 300 字用来精确检索，命中后带着父块一起返回，避免答案断章取义。

检索用的 BGE-M3，稠密加稀疏两路召回，融合之后过一遍 BGE-reranker 重排。查询这边做了分类：闲聊和通用问题直接答，专业问题才进知识库，另外支持子问题拆分和 HyDE 两种改写方式。

工程侧是 FastAPI + WebSocket 做流式输出，Redis 缓存热点问答，MySQL 存最近五轮会话。评测用 RAGAS 搭了一条流水线，从忠实度、相关性、检索精度、召回四个维度看效果。自建评测集上答案相关性 0.91 左右，高频咨询基本即问即答。

## 怎么跑

```
pip install -r requirements.txt
python app.py
```

配置文件在 `config.ini`，改数据库和模型相关的配置就行。
