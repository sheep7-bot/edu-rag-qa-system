# 知了问答（RAG 智能问答助手）

知了问答是一个面向考研备考（计算机 408）场景的智能答疑系统。学院把自己整理的讲义、大纲与习题解析等资料（PDF、Word、PPT、图片）导入进来，学生在网页上提问，系统基于这些资料回答知识点与常见问题等咨询，支持多轮对话和逐字流式输出。

核心思路是分两层：常见问题直接用 BM25 从 FAQ 库里匹配返回，不走大模型，响应快、成本低；匹配不上或置信度不够的，再进 RAG 流程，用 BGE-M3 做稠密加稀疏两路召回，融合后经 BGE-reranker 重排，交给大模型生成答案。

文档解析做了父子分块——父块 1200 字保上下文完整，子块 300 字用于精确检索，命中后带父块返回，避免答案断章取义。查询侧做了分类：通用问题直接答，专业问题才进知识库，另支持子问题拆分和 HyDE 两种改写。

工程侧是 FastAPI + WebSocket 流式输出，Redis 缓存热点问答，MySQL 存最近五轮会话。用 RAGAS 搭了评估流水线，从忠实度、相关性、检索精度、召回四个维度衡量，自建评测集上答案相关性约 0.91。

## 怎么跑

```
pip install -r requirements.txt
python app.py
```

数据库和模型配置在 `config.ini` 里改。
